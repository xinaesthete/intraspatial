One matrix, several statistics — they disagree, and that is the point. MH_PC is the paper's headline: a partial correlation, measuring A against B after conditioning on all 47 other types. Plain correlation is transitive, so everything that crowds into the same inflamed quadrats correlates with everything else and the matrix fills with one "this is where the cells are" factor; the partial version keeps only what survives that. Switch between QCM partial and QCM Pearson to watch the induced associations drop out: on COVID_SAMPLE_16_ROI_3, 68 of 1,128 pairs exceed |r| = 0.3 but only 8 exceed |partial| = 0.3, and after Benjamini–Hochberg 226 pairs survive on the plain correlation against 23 on the partial. gate q<α dims the pairs that fail BH — 1,128 simultaneous tests on one ROI, so the correction is not optional. 1000 shuffles is the paper's number, and the default here for a reason: a permutation p cannot fall below 1/(S+1), so BH can declare nothing at all until enough pairs pile up at that floor. At 199 shuffles that bar is 113 pairs and the partial correlation returns zero discoveries — which looks exactly like "no associations" and is not. The panel says so when it applies.

The g(r) chart carries two bands, and they answer different questions. The cyan one hugging the curve is a bootstrap confidence interval — how well g(r) itself is known, from resampling the anchor cells; it says nothing about whether the arrangement is unusual. The grey dashed one is the global rank envelope — where g(r) would lie under the null; a curve leaving it anywhere is significant at α, which a pointwise band cannot claim. Neither implies the other: a tight CI inside a wide envelope means "well measured, not unusual", and the reverse means "barely measured, but extreme".

Which null decides what is being tested, and the difference is not cosmetic. Random shift (Lotwick & Silverman 1982) translates B by a random vector, wrapping around the ROI: each type keeps its own clustering exactly and only the two patterns' relative position is destroyed, so what is tested is association. Random labelling shuffles the A/B labels between the same cells — right when A and B are nested or exchangeable subsets of one population (Fibroblast vs Prolif fibroblast), but for two distinct self-clustered types it asks "are these one interleaved population?", to which the answer is trivially no: on independent synthetic patterns that are each clustered it rejects 20 times out of 20, where the shift null rejects 3.

Radius is top-hat-equivalent: switching kernel rescales it to hold the probed scale (μ₂) fixed, so "smoother" never quietly becomes "more local". α=5, world units. ⚠ The store must be CORS-enabled (default: the local MDV server at localhost:5055); if unreachable, use fixture or open a CSV.

The MDV zarr row loads a converted MDV project (pnpm mdv:zarr). Such a project holds many ROIs — the covid project is 545,400 cells across 32 — and every statistic here is per ROI: ρB is a density over one ROI and the edge correction is against one ROI's boundary, so pooling them would measure the gaps between tissue sections. Hence the ROI picker. Scale comes from the project's own regions.scale rather than a default of 1; for covid that is exactly 1 µm/unit, so r=100 µm and σ=50 µm are literal. The g(r) this path produces is validated against the project's own published gr10/gr20 — 74,567 comparisons, median 0.26% (pnpm mdv:parity).
