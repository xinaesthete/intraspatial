Cell-type spatial statistics — TCM · cross-PCF · N-way matrix (Stream B2)

A SpatialData store is inspected for its tables and their candidate cell-type columns (auto-selected when there is only one); obsm/spatial centroids are then grouped into per-type clouds (ADR-0018 — never merged), each carrying a resolved placement. A CSV export or the offline fixture take the identical path. Hover the N-way matrix to link every view to that cell-type pair; click to pin it (leaving the matrix returns to the pinned pair). MuSpAn eqs 8–14, Mode 1 (faithful, global ρB). Γ is rendered as two additive GPU passes — B through a radial kernel, then A splatted with the transformed mark fetched per cell — with the exact CPU oracle one button away. The derivation is in docs/cell-stats.md.

—

Radius is top-hat-equivalent: switching kernel rescales it to hold the probed scale (μ₂) fixed, so "smoother" never quietly becomes "more local". α=5, world units. ⚠ The store must be CORS-enabled (default: the local MDV server at localhost:5055); if unreachable, use fixture or open a CSV.
