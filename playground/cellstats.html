Cell centroids → op-graph → per-type KDE splat (Stream B2)

A real SpatialData regions table (tables/Leap034_imc_cells) is read through zarrita: its obsm/spatial centroids are grouped by obs/cell_type_id into per-type point clouds (ADR-0018 — never merged), each carrying a resolved placement + provenance. The left panel scatters all centroids coloured by type; selecting a type runs the registered splatDensity KDE op on that cloud in the graph (right panel). This is the ingestion prerequisite for the cell-type spatial statistics (TCM, cross-PCF) to come.

world units; α=5 · Mode 1 (faithful, global ρB)

⚠ Expects a CORS-enabled SpatialData store (default the local MDV server at localhost:5055). If unreachable, use run fixture — it runs the identical ingestion + splat path on a synthetic 2-type cloud, offline.
