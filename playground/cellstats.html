Reading the two bands on g(r) — a confidence interval is not an envelope

The cyan band hugging the curve is a bootstrap confidence interval: how well g(r) itself is known. It says nothing about whether the arrangement is unusual. The grey dashed band is the global rank envelope: where g(r) would lie under the null, so a curve leaving it anywhere is significant at α — which a pointwise band cannot claim. Neither implies the other. A tight CI inside a wide envelope means "well measured, not unusual"; the reverse means "barely measured, but extreme".

Only the CI has a published counterpart. It is SpOOx's Loh spatial block bootstrap: resample 100 µm tiles with replacement, not anchor cells, and take the ratio Σcontributions/Σanchors. That choice is the difference between a band that works and one that lies — on a clustered pattern, resampling anchors independently covers the truth 40% of the time while claiming 95%, because neighbouring anchors see the same cells. The tiled version measures 98%. (The paper says a 20 µm lattice; the source hard-codes 100.) The envelope has no counterpart at all: SpOOx runs no null simulation for the cross-PCF, so it is a stronger inference offered here, not a reproduction.

Which envelope null — shift tests association, labelling tests exchangeability

Random shift (Lotwick & Silverman 1982) translates B by a random vector, wrapping around the ROI: each type keeps its own clustering exactly and only the two patterns' relative position is destroyed, so what is tested is association. Random labelling shuffles the A/B labels between the same cells — right when A and B are nested or exchangeable subsets of one population (Fibroblast vs Prolif fibroblast), but for two distinct self-clustered types it asks "are these one interleaved population?", to which the answer is trivially no: on independent synthetic patterns that are each clustered it rejects 20 times out of 20, where the shift null rejects 3.

The matrix layers disagree with each other, and that is the point

MH_PC is the paper's headline: a partial correlation, measuring A against B after conditioning on all 47 other types. Plain correlation is transitive, so everything crowding into the same inflamed quadrats correlates with everything else and the matrix fills with one "this is where the cells are" factor; the partial version keeps only what survives that. Switch between QCM partial and QCM Pearson to watch the induced associations drop out: on COVID_SAMPLE_16_ROI_3, 68 of 1,128 pairs exceed |r| = 0.3 but only 8 exceed |partial| = 0.3, and after Benjamini–Hochberg 226 pairs survive on the plain correlation against 23 on the partial. gate q<α dims the pairs that fail BH — 1,128 simultaneous tests on one ROI, so the correction is not optional.

Shuffle count sets what BH can resolve — and why the null runs on the GPU

A permutation p cannot fall below 1/(S+1), so BH can declare nothing at all until m/((S+1)·α) pairs pile up at that floor. At the paper's 1000 shuffles that bar is 23 pairs and exactly 23 clear it — the discovery set sits on the threshold, so it is unstable: two runs of the same null disagree on 6 of 1,128 pairs from Monte Carlo noise alone. At 199 shuffles the bar is 113 and the partial correlation returns zero discoveries, which looks exactly like "no associations" and is not. The matrix legend says so whenever the floor binds.

GPU null makes the fix affordable: the permutation is a Feistel cipher over the cell indices, so π(i) is O(1) per thread with no Fisher-Yates and no scratch, and the count, correlation and 49×49 inverse all run per-shuffle on the device. Measured back to back on COVID_SAMPLE_16_ROI_3, 9,999 shuffles in 668 ms against 42,364 ms on the CPU — 63×. The observed MH_PC is the identical f64 value either way; only the null is sampled on the device. QCM null picks the sampler: the label shuffle, or SpOOx's 2×2 swap chain, which reproduces the published MH_SES to within its own reproducibility.

Units, the radius convention, and what each source guarantees

Radius is top-hat-equivalent: switching kernel rescales it to hold the probed scale (μ₂) fixed, so "smoother" never quietly becomes "more local". α=5, world units.

The MDV project source loads a converted project (pnpm mdv:zarr). Such a project holds many ROIs — covid is 545,400 cells across 32 — and every statistic here is per ROI: ρB is a density over one ROI and the edge correction is against one ROI's boundary, so pooling them would measure the gaps between tissue sections. Hence the ROI picker. Scale comes from the project's own regions.scale rather than a default of 1; for covid that is exactly 1 µm/unit, so r=100 µm and σ=50 µm are literal. The g(r) this path produces is validated against the project's published gr10/gr20 — 74,567 comparisons, median 0.26% (pnpm mdv:parity).
