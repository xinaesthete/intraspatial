SpatialData raster tile → op-graph → Getis-Ord Gi* (Stream B1)

A real HTJ2K morphology channel is decoded per-chunk through the datasource Loader, converted to a graph grid field (tileToField), and run through the registered getisOrd op on the GPU. The right panel is the Gi* hot-spot z-score map (red = significantly high local density, blue = low). The same op is verified against a CPU golden in the automated suite; this page runs it on live bytes.

⚠ Expects a CORS-enabled SpatialData / OME-Zarr store hosted locally (default localhost:8080). If it is unreachable, use run fixture — it runs the identical graph on a dep-free synthetic plane, so the pipeline is demonstrable offline.
